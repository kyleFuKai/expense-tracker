## 二、平台投稿策略

### 2.1 稀土掘金（首选）

**为什么首选**：
- 2026年掘金重点扶持AI创作者
- [创作者签约计划](https://juejin.cn/post/7434698783642583059)：签约后单篇200-5,000元
- AI开发者创作激励：加精即得20-40元，最高1,000元
- 技术读者质量最高，传播力强

**投稿步骤**：
1. 注册/登录 [掘金](https://juejin.cn/)
2. 点击"写文章"
3. 粘贴Markdown内容（掘金支持Markdown）
4. 选择标签：`AI编程`、`Claude Code`、`效率工具`
5. 勾选"原创"
6. 发布

**提高收益的技巧**：
- 发布时间：**工作日早9-10点**或**晚8-9点**
- 发布后1小时内自己评论一条补充内容，增加互动
- 发布后分享到掘金"沸点"
- 参与掘金[AI编程话题活动](https://juejin.cn/ai)

**签约流程**：
1. 在掘金发布3篇以上优质原创技术文章
2. 关注官方"签约季"活动（每季度一次）
3. 提交申请 → 审核通过 → 获得签约资格
4. 签约后发布文章即有稿酬

### 2.2 知乎

**投稿方式**：
1. 注册知乎 → 写文章 → 粘贴内容
2. 投稿到[技术类话题](https://www.zhihu.com/topic/19554365/hot)
3. 可投稿到技术类公众号（见下方列表）

**变现方式**：
- 知乎盐选专栏（需要申请）
- 流量分成（阅读量越高收益越高）
- 引流到公众号/个人品牌

### 2.3 CSDN

**投稿方式**：
1. 登录 [CSDN](https://blog.csdn.net/)
2. 创建新文章 → 粘贴Markdown
3. 设置文章标签
4. 可选择加入"付费专栏"

**变现方式**：
- 付费专栏（9.9-99元/套）
- 创作激励（按阅读量）
- 打赏

### 2.4 腾讯云+社区

**投稿方式**：
1. 登录 [腾讯云开发者社区](https://cloud.tencent.com/developer)
2. 写文章 → 发布
3. 参与征文活动

**变现方式**：
- 优秀文章有稿费
- 引流接云服务

### 2.5 微信公众号

**自己开号**：
- 长期收益最高（粉丝资产）
- 变现方式：广告、付费阅读、赞赏、引流

**投稿给大号**（稿费参考）：

| 公众号 | 稿费 | 要求 |
|--------|------|------|
| 程序员鱼皮 | 200-500元 | AI编程方向 |
| 小林coding | 300-800元 | 后端/AI |
| JavaGuide | 200-500元 | Java+AI |
| 技术铅书 | 300-1000元 | 深度教程 |

## 七、注意事项

### 版权
- 每篇文章标注"原创"
- 允许转载但要求注明来源
- 不要在未发表前泄露内容

### 合规
- 不夸大AI能力（"取代程序员"之类的标题）
- 收入数据标注"真实但因人而异"
- 不推荐具体投资/创业行为

### 持续
- 保持每月1-2篇的更新频率
- 收集读者反馈，写他们想看的内容
- 建立系列品牌（"AI编程实战系列"）
