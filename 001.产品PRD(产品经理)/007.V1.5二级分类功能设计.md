# 二级分类功能设计文档 (V1.5)

> 版本：V1.5 | 状态：待实现 | 日期：2026-05-31

---

## 1. 需求概述

为分类体系增加**两级分类**能力——父分类 + 子分类。记账时通过顶部 Tab 选择父分类，再在网格中选择子分类，使分类更精细。

### 1.1 已有基础

- ✅ 数据库 `category.parent_id` 已建好（DDL `parent_id BIGINT UNSIGNED NOT NULL DEFAULT 0`）
- ✅ Java 实体有 `parentId` 字段，DTO 也有 `parentId`
- ✅ 创建分类接口已支持传 `parent_id`
- ✅ 返回数据中包含 `parent_id`
- ❌ 前端所有分类平铺成网格，不区分父子层级
- ❌ 类别管理页无法指定上级分类创建子分类

### 1.2 结论

**后端不需要修改！** 数据库、实体、DTO、Service、Controller 都已就绪。只需修改前端两个页面。

## 2. 记账页 (record.html) — 顶部 Tab + 子分类网格

### 2.1 交互逻辑

1. 调用 `GET /categories?type=EXPENSE`（或 INCOME）获取全部分类
2. 前端按 `parent_id` 分组：
   - `parent_id = 0` → 父分类
   - `parent_id > 0` → 归入对应父分类的子分类
3. 渲染为 **顶部横向滚动 Tab**（父分类） + **下方 4 列网格**（子分类）
4. 点击父分类 Tab → 切换显示其子分类
5. 如果某父分类**无子分类** → 点击 Tab 直接选中该父分类
6. 点击子分类 → 选中（蓝色高亮），即当前分类

### 2.2 UI 布局

```

│ 支出金额                    [保存]     │
│ ¥ 45.00                    [现在]     │
├────────────────────────────────────────┤
│ 分类                                    │
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐   │ ← 横向滚动 Tab
│ │餐饮│ │交通│ │购物│ │娱乐│ │更多│   │
│ └────┘ └────┘ └────┘ └────┘ └────┘   │
├────────────────────────────────────────┤
│                                        │
│  🍜      🌙      🍕      🧋            │ ← 子分类 4 列网格
│ 午餐    晚餐    夜宵    奶茶            │
│                                        │
│  🍝      (选中态，蓝色边框)             │
│ 其他                                   │
└────────────────────────────────────────┘
```

### 2.3 数据结构

前端处理后的结构：
```javascript
{
  parents: [
    { id: 1, name: "餐饮", icon: "restaurant", children: [
      { id: 10, name: "午餐", icon: "restaurant" },
      { id: 11, name: "晚餐", icon: "dining" },
      ...
    ]},
    { id: 2, name: "交通", icon: "directions_car", children: [] },
    ...
  ]
}
```

### 2.4 选中逻辑

- 父分类**无子分类** → 选中该父分类本身，`selectedCategoryId = parentId`
- 父分类**有子分类** → 选中子分类，`selectedCategoryId = childId`
- 账单的 `category_id` 始终指向**最后选中的分类 ID**（无论是父还是子）

## 3. 类别管理页 (category-manage.html) — 支持创建子分类

### 3.1 改动点

#### 添加分类弹窗 — 新增"上级分类"选择器

新增下拉选择框，默认值"无（作为一级分类）"，选项为当前类型下的所有一级分类。

```
┌────────────────────────────────┐
│ 添加自定义分类                 │
├────────────────────────────────┤
│ 分类名称                       │
│ [输入分类名称       ]          │
│                                │
│ 选择图标                       │
│ [图标网格...]                  │
│                                │
│ 类型                           │
│ [支出] [收入]                  │
│                                │
│ 上级分类           ← 新增字段  │
│ [ 无（作为一级分类） ▾]        │
│                                │
│ [取消]        [保存]           │
└────────────────────────────────┘
```

#### 分类展示 — 子分类在父分类下方缩进

- 父分类正常显示（3 列网格）
- 每个父分类下方显示其子分类（3 列网格，缩进 + 左边竖线标识）
- 自定义分类显示删除按钮，系统预设分类标记"系统预设"

#### 后端请求

- 创建分类：`POST /categories` → body 增加 `parent_id` 字段（默认 0）
- 其余接口不变（GET list / DELETE / PUT）

## 4. 数据流

```
┌──────────────┐
│ category DB  │  parent_id → 0 = 父分类, > 0 = 子分类
└──────┬───────┘
       │ GET /categories?type=EXPENSE
       ▼
┌──────────────┐
│ 前端 JS      │  按 parent_id 分组 → parents + children
│ (record.html)│  渲染 Tab + 网格
└──────┬───────┘
       │ 用户选分类 → selectedCategoryId = childId/parentId
       │ POST /api/bills { category_id: selectedCategoryId, ... }
       ▼
┌──────────────┐
│ bill DB      │  category_id → 指向选中的分类（父或子）
└──────────────┘
```
