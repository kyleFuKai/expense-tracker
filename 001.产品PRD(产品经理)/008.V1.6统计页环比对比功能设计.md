# 统计页环比对比功能设计文档 (V1.6)

> 版本：V1.6 | 状态：待实现 | 日期：2026-05-31

## 1. 需求概述

在统计页的支出/收入卡片中增加**本月 vs 上月环比对比**，让用户一眼看出消费趋势变化。

### 1.1 已有基础

- ✅ Java `BillServiceImpl.monthlyStats()` 已实现当月统计（支出总额、收入总额、日趋势、分类排行）
- ✅ Node.js `/api/bills/stats/month` 已实现当月统计
- ✅ `BillMapper.selectSumAmount()` 可复用查询上月支出
- ❌ 无环比 SQL/计算逻辑
- ❌ 前端无环比展示

### 1.2 环比计算公式

```
环比% = (本月 - 上月) / 上月 × 100
上月为 0 → 环比显示 "--"
```

## 2. Java 后端设计

### 2.1 BillStatsVO 新增字段

```java
/** 支出环比（%），正数=增长，负数=下降 */
private BigDecimal expenseChange;

/** 收入环比（%），正数=增长，负数=下降 */
private BigDecimal incomeChange;
```

### 2.2 BillServiceImpl.monthlyStats() 变更

在现有统计逻辑之后，新增：

```java
// 计算上月日期
LocalDateTime prevMonthStart = start.minusMonths(1);
LocalDateTime prevMonthEnd = start; // 本月第一天即上月结束

// 查询上月支出
List<Bill> prevBills = billMapper.selectList(
    new LambdaQueryWrapper<Bill>()
        .eq(Bill::getUserId, userId)
        .between(Bill::getBillTime, prevMonthStart, prevMonthEnd)
);

BigDecimal prevExpense = prevBills.stream()
    .filter(b -> "EXPENSE".equals(b.getType()))
    .map(Bill::getAmount).reduce(BigDecimal.ZERO, BigDecimal::add);
BigDecimal prevIncome = prevBills.stream()
    .filter(b -> "INCOME".equals(b.getType()))
    .map(Bill::getAmount).reduce(BigDecimal.ZERO, BigDecimal::add);

// 计算环比
stats.setExpenseChange(calculateChange(expenseTotal, prevExpense));
stats.setIncomeChange(calculateChange(incomeTotal, prevIncome));
```

新增辅助方法：

```java
private BigDecimal calculateChange(BigDecimal current, BigDecimal previous) {
    if (previous.compareTo(BigDecimal.ZERO) == 0) {
        return null; // 上月为 0，无环比
    }
    return current.subtract(previous)
        .multiply(BigDecimal.valueOf(100))
        .divide(previous, 1, RoundingMode.HALF_UP);
}
```

### 2.3 BillMapper 新增汇总收入方法

```java
@Select("SELECT COALESCE(SUM(amount), 0) FROM bill " +
        "WHERE user_id = #{userId} AND type = 'INCOME' " +
        "AND bill_time >= #{startDate} AND bill_time <= #{endDate}")
BigDecimal selectSumIncome(
    @Param("userId") Long userId,
    @Param("startDate") String startDate,
    @Param("endDate") String endDate
);
```

## 3. Node.js 后端设计

### 3.1 routes/bills.js — stats 接口变更

在现有 stats 逻辑中，除了本月数据外，额外查询上月数据并计算环比：

```javascript
// 计算上月
const prevMonth = month ? moment(month, 'YYYY-MM').subtract(1, 'month').format('YYYY-MM')
                         : moment().subtract(1, 'month').format('YYYY-MM');

// 查询上月支出和收入
const [[{ expense: prevExpense }]] = await pool.query(
    "SELECT COALESCE(SUM(amount), 0) AS expense FROM bill WHERE user_id = ? AND type = 'EXPENSE' AND DATE_FORMAT(bill_time, '%Y-%m') = ?",
    [user.id, prevMonth]
);
const [[{ income: prevIncome }]] = await pool.query(
    "SELECT COALESCE(SUM(amount), 0) AS income FROM bill WHERE user_id = ? AND type = 'INCOME' AND DATE_FORMAT(bill_time, '%Y-%m') = ?",
    [user.id, prevMonth]
);

// 计算环比
const calcChange = (curr, prev) => prev > 0 ? parseFloat(((curr - prev) / prev * 100).toFixed(1)) : null;

res.json({
    code: 0,
    data: {
        expense: { total: parseFloat(expense.total), count: expense.count, change: calcChange(parseFloat(expense.total), parseFloat(prevExpense)) },
        income: { total: parseFloat(income.total), count: income.count, change: calcChange(parseFloat(income.total), parseFloat(prevIncome)) },
        daily: ...,
        categories: ...
    }
});
```

## 4. 前端设计 (statistics.html)

### 4.1 总支出卡片

在现有 `stat-expense-count` 下方增加环比显示：

```html
<div id="stat-expense-change" class="mt-1 text-body-sm font-medium"></div>
```

JavaScript 渲染逻辑：

```javascript
var changeEl = document.getElementById('stat-expense-change');
if (data.expense.change !== null && data.expense.change !== undefined) {
    var ch = data.expense.change;
    var arrow = ch >= 0 ? '↑' : '↓';
    var colorClass = ch >= 0 ? 'text-danger-expense' : 'text-success-growth';
    changeEl.className = 'mt-1 text-body-sm font-medium ' + colorClass;
    changeEl.textContent = arrow + ' ' + Math.abs(ch) + '% 较上月';
} else {
    changeEl.textContent = '-- 较上月';
    changeEl.className = 'mt-1 text-body-sm text-on-surface-variant';
}
```
